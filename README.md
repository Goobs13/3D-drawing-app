# 3D Drawing App
A lightweight, web-based tool for creating and exporting 3D sketches.

## How to use
Interact: Click and drag your mouse to rotate the view of your 3D canvas.

Export: Use the built-in export functionality to save your creations as 3D files.

## Features
Built with Three.js for high-performance 3D rendering.

Completely self-contained and runs locally in your browser.

Supports GLTF format exporting for use in other 3D software

## About
This project is an experimental 3D sketching application designed for quick prototyping and creative exploration.
